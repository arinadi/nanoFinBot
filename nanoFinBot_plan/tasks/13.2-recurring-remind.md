# 13.2 - Remind when a recurring item is due

## Behavior

> "System reminds the group when a recurring item is due."

## Increment

On startup (and periodically while running), items whose `next_due` has passed trigger a
reminder message and their `next_due` advances by the frequency.

## Depends on

02, 03, 13.1

## Requirements

- On bot startup, check all active recurring items; for each whose `next_due` ≤ today,
  send a reminder to the group and advance `next_due` by the frequency.
- While running, re-check on a schedule (e.g. hourly); no duplicate reminder for the
  same period.
- Sending a reminder never creates a transaction (reminder only, context Q16).

## Data and API

- RecurringItem due-check + `advance_next_due`; uses the bot's send path (03).

## Technical notes

- Idempotent: advancing `next_due` before/after sending must not double-fire on restart.
