# 00.1 - Project scaffold and `nfb` entry point

## Behavior

> "System installs and exposes the `nfb` command from a clean checkout."

## Increment

The project is a pip-installable Python package; `pip install -e .` in a venv
succeeds and `nfb --version` prints the version.

## Depends on

none

## Requirements

- `pyproject.toml` exists with pinned deps (see `architecture.md` §1) and
  `[project.scripts] nfb = "nanofinbot.cli:main"`.
- `nanofinbot/` package exists with `__init__.py` and `cli.py` exposing `main()`.
- `nfb --version` prints the version from the package metadata.
- Works on Python 3.12.

## Data and API

- Command: `nfb --version` → prints `nfb <version>`.

## Technical notes

- Use setuptools or hatchling as the build backend; either is fine, pick one and keep it.
- `cli.py` uses `argparse` with a `--version` action; subcommands come in later tasks.
- Pin deps as ranges (`aiogram>=3,<4`, `openai>=1,<2`, `aiosqlite>=0.20,<0.21`,
  `reportlab>=4,<5`, `Pillow>=10,<11`, `platformdirs>=4,<5`).
- See `reference/code-layout.md`.

## Acceptance checks

- [ ] `pip install -e .` succeeds in a fresh venv on Python 3.12
      Command: `python3 -m venv .venv && .venv/bin/pip install -e .`
- [ ] `nfb --version` prints a version string and exits 0
      Command: `.venv/bin/nfb --version`
