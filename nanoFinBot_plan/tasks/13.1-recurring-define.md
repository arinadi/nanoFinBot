# 13.1 - Define a recurring item

## Behavior

> "User can define a recurring item."

## Increment

A command lets the user add (and list) a recurring item with description, amount,
frequency, and next due date.

## Depends on

02, 03

## Requirements

- A command (e.g. `/recurring add`) collects description, amount, currency, type,
  frequency (daily/weekly/monthly/yearly), and first due date.
- `/recurring list` shows the active recurring items.
- Items are stored in the `recurring` table.

## Data and API

- Entity: RecurringItem (see `architecture.md` §2).

## Technical notes

- Recurring items are reminders only — no transaction is auto-created (context Q16).
