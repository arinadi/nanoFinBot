# 11.1 - Auto-create a category

## Behavior

> "System creates a category when the bot categorizes a draft."

## Increment

When parser/OCR suggest a category name that does not exist, it is created in the DB.

## Depends on

02, 06

## Requirements

- When a draft carries a `category` (from 06 or 07) that is not in `categories`, the
  category is created before the draft is saved.
- A category with an existing name is reused (case-insensitive), never duplicated.

## Data and API

- Entities: Category (create + lookup by name).
- Function: `get_or_create_category(name) -> id`.

## Technical notes

- Normalize category names (trim, title-case) before lookup to avoid near-duplicates.

## Acceptance checks

- [ ] Saving a draft with a new category creates it
      Command: `python -m pytest tests/test_categories.py::test_auto_create -q`
- [ ] Saving a draft with an existing category reuses it (no duplicate)
      Command: `python -m pytest tests/test_categories.py::test_no_duplicate -q`
