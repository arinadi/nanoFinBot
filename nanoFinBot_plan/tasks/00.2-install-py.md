# 00.2 - `install.py` installer

## Behavior

> "User can install nanoFinBot by running install.py."

## Increment

Running `install.py` on a clean machine produces a working `nfb` command.

## Depends on

00.1

## Requirements

- `install.py` creates a venv, installs the pinned deps, then `pip install -e .`.
- Idempotent: running it twice does not break the existing install.
- Cross-platform: works on Linux and Windows (use `sys.executable`, no shell-only
  constructs like `source`).
- `nfb` is on PATH for the current user after a successful run.

## Data and API

- Command: `python install.py` (or `./install.py`).

## Technical notes

- Build the venv at a stable location (e.g. `~/.local/share/nfb/venv` via
  `platformdirs`), then run `<venv>/bin/python -m pip install -e <repo>`.
- On Windows the pip entry point lives at `<venv>/Scripts/nfb.exe`; handle the
  platform bin/Scripts path split.
- Editable install is what makes `git pull` updates appear in `nfb` automatically
  (context Q20) — do not copy or symlink files.
- Print clear success output including the venv path and how to run `nfb`.

## Acceptance checks

- [ ] On a clean checkout, `python install.py` succeeds and `nfb --version` works
      Command: `python install.py && nfb --version`
- [ ] Running `install.py` a second time exits 0 without errors
      Command: `python install.py && python install.py`
