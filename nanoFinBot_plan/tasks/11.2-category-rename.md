# 11.2 - Rename a category

## Behavior

> "User can rename a category."

## Increment

A bot command lists categories and lets the user rename one; existing transactions keep
the new name (foreign key by id, not name).

## Depends on

02, 03

## Requirements

- A command (e.g. `/categories`) lists categories; choosing one prompts for a new name.
- Renaming updates the `categories` row; transactions referencing it are unaffected.
- Empty or duplicate names are rejected with a clear message.

## Data and API

- Uses `list_categories()` and a new `rename_category(id, name)` in 02.

## Technical notes

- Because transactions reference `category_id`, a rename is a single UPDATE with no
  migration of rows.
