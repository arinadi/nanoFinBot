# 08.3 - Cancel a draft

## Behavior

> "User can cancel a draft."

## Increment

Pressing Cancel removes the draft row and confirms the drop.

## Depends on

08.1

## Requirements

- Pressing Cancel deletes the `draft` row and replies confirming it was discarded.
- A canceled draft never appears in reports or exports.

## Data and API

- Deletes the `status=draft` row (only drafts are deletable; active/disabled rows are not).

## Technical notes

- Deleting a draft is the one legitimate delete in the system (it was never saved).
