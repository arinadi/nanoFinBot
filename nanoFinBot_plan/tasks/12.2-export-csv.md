# 12.2 - CSV export

## Behavior

> "User can request a CSV export and receive it as a Telegram document."

## Increment

A command generates a CSV of transactions and sends it as a document on the same
on-demand path as the PDF, excluding disabled transactions.

## Depends on

02, 03, 09

## Requirements

- A command (e.g. `/export`) generates a CSV with columns
  `date, type, amount, currency, category, description` and sends it via `answer_document`.
- `disabled` transactions are excluded.
- The CSV path shares the request→format→send flow with 12.1 (context Q18).

## Data and API

- Reads active transactions from 02; uses stdlib `csv`.

## Technical notes

- Use `io.StringIO` + `csv.writer`, encode UTF-8 (include BOM for Excel on Windows).

## Acceptance checks

- [ ] `/export` produces CSV bytes whose rows match the stored active transactions
      Command: `python -m pytest tests/test_reports.py::test_csv_rows -q`
- [ ] A disabled transaction is absent from the CSV
      Command: `python -m pytest tests/test_reports.py::test_csv_excludes_disabled -q`

- PDF report — 12.1.
