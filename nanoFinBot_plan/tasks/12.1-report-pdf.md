# 12.1 - PDF report

## Behavior

> "User can request a PDF report and receive it as a Telegram document."

## Increment

A command generates a PDF summary (totals by category + period) and sends it as a
document, excluding disabled transactions.

## Depends on

02, 03, 09

## Requirements

- A command (e.g. `/report`) generates a PDF for the current month (or requested period):
  header, income vs expense totals, and a per-category table and bar chart.
- Amounts are formatted with the `CURRENCIES` symbol (multi-currency rows grouped or
  labeled by code).
- `disabled` transactions are excluded.
- The PDF is sent via `answer_document` as a file (see `reference/reportlab-pdf.md`).

## Data and API

- Reads `list_transactions(...)` (active only) from 02.
- Function: `build_pdf(transactions, period) -> bytes`.

## Technical notes

- Use reportlab built-in fonts (Helvetica) — no font files on Alpine.
