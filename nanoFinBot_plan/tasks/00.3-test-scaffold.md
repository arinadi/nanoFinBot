# 00.3 - Test scaffold

## Behavior

> "System runs the test suite with a passing placeholder test."

## Increment

## Depends on

## Requirements

- `pytest` and `pytest-asyncio` are in the dev dependency group.
- `pytest.ini`/`pyproject` configures asyncio mode (auto).
- `tests/conftest.py` exists with the async fixtures later tasks will extend
  (a tmp config dir, a tmp DB path).
- A placeholder test passes.

## Data and API

- Command: `python -m pytest` (runs green).

## Technical notes

- Set `asyncio_mode = auto` so `async def test_*` works without markers.
- Add the dev deps under an `optional-dependencies = { dev = [...] }` group.

      Command: `python -m pytest -q`
